# Decision records

Every decision that shapes the architecture is written down here before the code
that depends on it exists. The shape a record takes, how it is numbered, and
what happens to one that is later replaced are all fixed by record
[0000](0000-how-a-decision-is-recorded.md).

This index lists every record. A record is present here or it is not landed.

Numbers are assigned when the decision is planned, so a gap in this table is a
record that has not landed yet rather than one that was removed. Nothing is ever
renumbered and nothing is ever deleted; a decision that is replaced keeps its
row and its status says which record replaced it.
